> **문제 정의**: 같은 구조의 생성자에 VAE식 학습 신호(Encoder + 재구성 손실)를 더하면, 조건부 이미지 생성이 더 좋아지는가?

Fashion-MNIST에서 라벨을 주면 그 클래스의 옷 이미지를 만드는 모델을 두 가지 방식으로 학습해 비교했다. 두 모델은 생성 경로(Generator, Discriminator, 라벨 주입, 손실함수)가 완전히 같고, cVAE-GAN에만 Encoder와 재구성 손실이 더해진다. 그래서 이 실험에서 바뀌는 것은 생성자의 **구조가 아니라 생성자를 학습시키는 방식**이다.

"더 좋다"는 말이 모호하므로 네 가지 하위 질문으로 나눴다.

| 하위 질문 | 측정 지표 |
| --- | --- |
| Q1. 라벨을 더 잘 따르는가? | 조건부 정확도 |
| Q2. 더 사실적인가? | FID, Precision |
| Q3. 더 다양한가? | Recall, 클래스 내 다양성 비율 |
| Q4. 더 안정적으로 학습되는가? | loss·D 출력 추이, FID 곡선의 흔들림 |

## 한 줄 요약

- VAE식 학습 신호는 조건부 생성을 **전반적으로 좋게 만들지 않았다.** 예상대로 trade-off가 나왔다.
- **사실성은 cGAN**이 앞섰다: test FID **10.35 vs 15.26**, Precision 0.854 vs 0.826, 클래스별 FID는 10개 클래스 모두 cGAN이 낮다.
- **다양성은 cVAE-GAN**이 앞섰다: Recall **0.738 → 0.802**, 다양성 비율 0.962 → 1.004. 대신 epoch당 학습 시간이 약 2배다.

| --- | --- |
| 데이터 | Fashion-MNIST (Zalando), 28×28 흑백 |
| 규모 | train 60,000 / test 10,000 |
| 클래스 | T-shirt/top, Trouser, Pullover, Dress, Coat, Sandal, Shirt, Sneaker, Bag, Ankle boot (10개) |

## 1. 데이터 확인

학습 전에 데이터를 본 목적은 세 가지다. 전처리 근거를 확보하고, 생성 결과와 비교할 기준점을 만들고, 결과 해석에 쓸 가설을 미리 세우는 것이다.

### 무결성과 분포

- 이미지·라벨 개수가 일치하고, 값은 uint8 0~255, NaN·빈 이미지는 0장이다. 정제할 것이 없다.
- 10개 클래스 모두 train 6,000 / test 1,000장으로 완전히 균등하다. 그래서 생성·평가 때 클래스당 같은 장수(1,000장)로 라벨을 균등하게 뽑으면 된다.
- 픽셀의 50.2%가 배경(0)이다. [-1, 1]로 정규화하면 배경이 정확히 -1에 놓인다.
- train과 test의 클래스별 픽셀 평균 차이는 최대 0.006, 표준편차 차이는 최대 0.005다. test를 FID의 실제 기준으로 써도 된다.

### 중복과 누수: test가 train과 겹치지 않는가

FID와 Precision을 test 기준으로 재므로, test 이미지가 train에 거의 그대로 들어 있으면 점수가 낙관적으로 나온다. 두 단계로 확인했다.

- **완전 중복(md5)**: train 내부, test 내부, train↔test 모두 0장이다. 같은 이미지인데 라벨이 다른 경우도 0건이다.
- **근접 중복**: 처음에는 perceptual hash(pHash) 해밍 거리 ≤ 4로 판정하려 했다. 그런데 28×28에서는 pHash가 실루엣 정도만 구분한다.

![](https://velog.velcdn.com/images/def_uk/post/ece36be2-ac06-4979-b9e3-f43f75c96132/image.png)

왼쪽은 test 이미지마다 가장 가까운 train 이미지까지의 pHash 해밍 거리, 오른쪽은 pHash 후보 쌍의 픽셀 RMS 거리다. 해밍 거리 ≤ 4만으로 자르면 test의 28%가 걸리지만, 픽셀 거리로 보면 대부분의 쌍이 RMS 30~60에 몰려 있다. 실루엣만 비슷하고 실제로는 다른 이미지라는 뜻이다.

그래서 pHash는 후보를 고르는 데만 쓰고, 최종 판정은 픽셀 RMS 거리로 했다.

| 단계 | test 이미지 | 비율 | 라벨이 다른 쌍 |
| --- | --- | --- | --- |
| pHash ≤ 4 (후보) | 2,842 | 28.42% | 6,072 |
| + RMS ≤ 5 | 6 | 0.06% | 0 |
| **+ RMS ≤ 10 (채택)** | **13** | **0.13%** | **0** |
| + RMS ≤ 20 | 153 | 1.53% | 0 |

![](https://velog.velcdn.com/images/def_uk/post/e6508a9d-bf85-4f6b-9e2a-5f48141de628/image.png)

위 네 줄은 RMS ≤ 10으로 확정한 근접 중복 쌍(test | train)이고, 마지막 줄은 임계값 바로 바깥(RMS > 10)에서 기각한 쌍이다. 확정 쌍은 눈으로 봐도 같은 상품이다. 거의 같은 이미지는 test의 0.13%뿐이므로, test 기준 점수가 낙관적으로 치우치는 정도는 무시할 수준이다.

### 가설

데이터 확인 결과와 두 모델의 일반적인 성질을 바탕으로 세운 가설이다.

| 가설 | 내용 |
| --- | --- |
| H1 | cGAN이 더 선명하지만 mode collapse 위험이 커서 클래스별 FID 편차가 크다 |
| H2 | cVAE-GAN이 다양성이 더 높고 학습이 안정적이지만 약간 흐리다 |
| H3 | 두 모델 모두 Shirt / T-shirt / Pullover / Coat의 조건부 정확도가 가장 낮다 |

## 2. 두 모델을 공정하게 비교하기

### 모델 구성

| 구성 요소 | cGAN | cVAE-GAN |
| --- | --- | --- |
| Generator (= Decoder) | DCGAN 스타일, z(100) + 라벨 임베딩(50) concat, 출력 tanh | 동일 |
| Discriminator | DCGAN 스타일 Conv, 라벨 입력, 출력은 sigmoid 없는 logit | 동일 (중간층 feature도 반환) |
| Encoder | - | (x, y) → μ, logσ² |
| 손실 | BCEWithLogits, non-saturating G loss | 동일 + KL + feature 재구성 |

cVAE-GAN은 Larsen et al.(2016)의 VAE-GAN에 라벨 조건만 더한 버전이다. 재구성 손실을 픽셀 MSE가 아니라 **Discriminator 중간층 feature끼리의 MSE**로 잰다. 픽셀 MSE를 쓰면 VAE 특유의 흐린 이미지가 나오기 때문이다. 모듈별로 받는 손실은 다르다.

| 모듈 | 업데이트에 쓰는 손실 |
| --- | --- |
| Encoder | KL + feature 재구성 |
| Decoder | γ(=1.0) × feature 재구성 + GAN (재구성 x̃, prior 샘플 모두 진짜로 속이기) |
| Discriminator | GAN (실제 → 1, 재구성 x̃ → 0, prior 샘플 → 0) |

### 공정 비교 조건

| 항목 | 설정 |
| --- | --- |
| Generator / Discriminator | 구조·초기 가중치 동일 (G 2,409,204 / D 473,380 파라미터) |
| z_dim, 라벨 주입 | 100, Embedding concat |
| optimizer | Adam, lr 2e-4, β1 0.5 |
| batch size | 128 |
| 학습량 | 최대 50 epoch, 같은 시드(42) |
| 조기종료 | val FID 기준, 10 epoch(평가 2회) 동안 개선 없으면 중단 |

cVAE-GAN은 Encoder(1,288,684) 때문에 파라미터가 약 1.45배 많다. 하지만 생성할 때는 Encoder를 쓰지 않으므로 생성 경로는 같다.

조건이 정말 같은지는 학습 전 상태로 확인했다. 두 모델을 초기화만 하고 같은 평가를 돌리면, 생성 경로 지표 **48개가 완전히 같게(최대 차이 0.0)** 나왔다.

## 3. 평가 도구 만들기

### 평가용 분류기

조건부 정확도, Precision/Recall, 다양성 비율은 모두 분류기에 의존한다. 그래서 분류기를 먼저 만들고, 어디서 틀리는지 확인한 뒤 확정했다.

- 모델: 28×28용으로 고친 ResNet-18(입력 1채널, 첫 conv 3×3 stride 1, maxpool 제거), 사전학습 없이 학습
- 1차 학습(v0): val 정확도 0.9395. 그런데 train 정확도가 epoch 12부터 1.000이고, val loss는 epoch 4가 최저였다가 끝까지 올랐다. **과적합이 일어나고 예측이 과신된 상태**였다(ECE 0.044).

과적합을 줄일 후보를 한 번에 하나씩 추가하고, val 정확도가 0.002 이상 오를 때만 채택했다.

![](https://velog.velcdn.com/images/def_uk/post/82194fc4-dd23-4822-aa48-2357757a793b/image.png)

왼쪽 val loss에서 v0(파란색)만 epoch 4 이후로 올라간다. RandomCrop을 넣은 나머지 후보는 끝까지 내려간다.

| 후보 | val acc | 개선폭 | 최종 train acc | ECE | Shirt acc | 채택 |
| --- | --- | --- | --- | --- | --- | --- |
| v0 | 0.9395 | - | 1.0000 | 0.0440 | 0.819 | 기준선 |
| **crop** | **0.9493** | **+0.0098** | 0.9750 | **0.0171** | **0.853** | **O** |
| crop + weight decay | 0.9494 | +0.0001 | 0.9754 | 0.0190 | 0.861 | X |
| crop + flip | 0.9493 | +0.0000 | 0.9607 | 0.0103 | 0.847 | X |
| crop + rotation 10° | 0.9460 | -0.0033 | 0.9540 | 0.0104 | 0.846 | X |

- crop 하나로 과적합이 사라졌다. train 정확도가 0.975에서 멈추고 ECE가 절반 이하로 줄었다.
- crop에서 개선이 크게 나왔으므로 과적합 원인을 데이터 다양성 부족으로 보고 flip·rotation도 시험했다. val loss와 ECE는 조금 더 낮아졌지만 정확도는 오르지 않았고, Shirt 정확도는 오히려 떨어졌다. crop만으로 과적합이 이미 해결됐으므로 증강을 더 넣으면 학습만 어려워진다.
- label smoothing은 처음부터 제외했다. feature 군집을 압축해서 이 분류기로 재는 다양성 비율과 Precision/Recall을 왜곡하기 때문이다.

![](https://velog.velcdn.com/images/def_uk/post/ec0a86ab-d7ea-4e0a-8504-f5c7abe13e67/image.png)

crop과 v0의 혼동행렬 차이다(빨강 = crop에서 증가). 대각선에서 Shirt가 +3.3%p로 가장 많이 좋아졌고, Shirt를 T-shirt로 잘못 본 비율이 1.4%p 줄었다.

최종 분류기 val 정확도 **0.9493**이 생성 이미지 조건부 정확도의 사실상 상한이다. 클래스별로는 Shirt 0.853이 가장 낮고, T-shirt/top 0.910, Pullover 0.927, Coat 0.929 순이다. 분류기도 데이터 확인에서 예상한 상의 4개 클래스를 가장 많이 틀린다.

### 지표와 기준선

| 지표 | 하위 질문 | 측정 공간 | 해석 |
| --- | --- | --- | --- |
| 조건부 정확도 | Q1 | 분류기 예측 | 높을수록 좋음 |
| FID (전체·클래스별) | Q2 | Inception | 낮을수록 좋음 |
| Precision / Recall (k=3) | Q2 / Q3 | 분류기 feature | 품질과 다양성을 분리 측정 |
| 클래스 내 다양성 비율 | Q3 | 분류기 feature | 생성끼리 평균 거리 ÷ 실제끼리 평균 거리. 1보다 많이 작으면 mode collapse |
| 최근접 train 거리 비율 | memorization | 분류기 feature | 1보다 많이 작으면 train 복사 의심 |

- FID는 다른 연구와 비교할 수 있게 Inception feature로 쟀다. 나머지 지표는 Inception이 28×28 흑백 의류의 차이를 잘 못 잡을 수 있어서, Fashion-MNIST로 학습한 분류기의 512차원 feature 공간에서 쟀다.
- 조건부 정확도는 같은 이미지만 반복해도 100%가 나올 수 있다. 그래서 항상 다양성 비율, Recall, FID와 함께 읽는다.

지표의 범위를 감 잡기 위해, 학습 전 G(하한)와 실제 val 이미지(상한 쪽)를 생성 이미지 자리에 넣고 같은 지표를 계산했다.

| 지표 | 학습 전 G | 실제 val |
| --- | --- | --- |
| FID | 457.71 | 2.51 |
| 조건부 정확도 | 0.1000 | 0.9495 |
| Precision / Recall | 0.003 / 0.000 | 0.880 / 0.883 |
| 다양성 비율 | 0.217 | 0.997 |
| 최근접 train 거리 비율 | 2.49 | 1.00 |

- 실제 이미지인데도 Precision·Recall이 1이 아니라 0.88이다. k-NN으로 manifold를 근사하는 방식의 한계이므로 0.88을 사실상 상한으로 본다.
- 실제 val의 클래스별 FID는 10~21로 전체 FID(2.51)보다 훨씬 크다. 클래스당 1,000장으로 2048차원 공분산을 추정하면 값이 위로 치우친다. 그래서 클래스별 FID는 두 모델 사이의 상대 비교에만 썼다.

### test로 모델을 고르지 않기

처음에는 학습 중 평가(best 체크포인트 선택, 조기종료)도 test로 했다. 그러면 **test로 모델을 고르는 셈**이라 최종 test 점수가 낙관적으로 치우친다. 그래서 학습 중 평가는 val의 클래스당 1,000장(test와 같은 10,000장이라 FID 크기 비교 가능)으로 옮기고, test는 best 체크포인트를 최종 평가할 때 한 번만 썼다.

### 스모크 테스트

본 학습 전에 축소 설정(train 10배치, 2 epoch, 클래스당 50장)으로 파이프라인 전체를 점검했다. 하이퍼파라미터는 그대로 두고 데이터 양과 epoch만 줄였다. 두 모델 모두 11단계를 전부 통과했다.

| 확인 항목 | 결과 |
| --- | --- |
| D 출력에 sigmoid 중복 없음 | 초기 logit의 82~86%가 [0, 1] 밖 |
| 라벨 주입 | 같은 z, 라벨만 바꾼 출력의 L2 거리 평균 0.60 |
| 업데이트 경로 | 각 optimizer가 자기 모듈만 바꿈, D 업데이트 때 G·E에 gradient 없음 |
| cVAE-GAN 소규모 과적합 | feature 재구성 0.407 → 0.194, KL이 0으로 붕괴하지 않음 |
| 체크포인트 재개 | loss 차이 최대 1.7e-3 (MPS 비결정 연산), RNG·fixed noise는 정확히 일치 |

이때 잰 iteration 시간이 cGAN 22ms, cVAE-GAN 49ms다. cVAE-GAN이 Encoder와 재구성 경로 때문에 약 2.2배 느리다.

| epoch | 5 | 10 | 20 | 30 | 35 | 45 |
| --- | --- | --- | --- | --- | --- | --- |
| val FID | 50.99 | 28.46 | 17.32 | 15.97 | **15.52** | 15.71 |

## 6. 가설 검증

| 가설 | 결과 | 판정 |
| --- | --- | --- |
| H1. cGAN이 더 선명하지만 mode collapse 위험이 커서 클래스별 FID 편차가 크다 | 사실성: FID·Precision·클래스별 FID 모두 cGAN 우세 → O<br>mode collapse: 다양성 비율 0.962(클래스별 0.886~1.036). 예상대로 Shirt가 가장 낮지만 붕괴 수준은 아님 → X<br>클래스별 FID 편차: cGAN 5.19 < cVAE-GAN 9.09로 **반대** | 부분 지지 |
| H2. cVAE-GAN이 다양성이 더 높고 학습이 안정적이지만 약간 흐리다 | 다양성: Recall 0.802 vs 0.738, 다양성 비율 1.004 vs 0.962 → O<br>안정성: D(x)가 0.5 근처 유지, val D(x) 흔들림 std 0.077 vs 0.101 → O. 다만 cGAN도 발산·붕괴가 없어서 실질 차이는 작다<br>흐림: 흐리지 않고 오히려 질감이 과하다 → X | 부분 지지 |
| H3. 두 모델 모두 Shirt / T-shirt / Pullover / Coat의 조건부 정확도가 가장 낮다 | 두 모델 모두 하위 4개 클래스가 **정확히 이 4개**다. 혼동 방향도 데이터 확인의 유사도 상위 쌍과 같다(Coat→Shirt 0.141 / 0.111, T-shirt→Shirt 0.132 / 0.107) | 지지 |

- H2의 "흐림"이 틀린 것은 재구성 손실을 픽셀이 아니라 D feature로 잰 효과로 보인다. Larsen et al.(2016)이 이 방식으로 의도한 효과다. cVAE-GAN의 FID가 높은 원인은 흐림이 아니라 부자연스러운 질감이다.
- H3를 분류기 상한과 나란히 보면, cGAN의 Shirt(0.842 vs 상한 0.853)는 분류기 한계에 거의 닿아 있다. 생성 모델 자체의 문제가 큰 곳은 cGAN의 **Coat**(상한 대비 -0.135)와 cVAE-GAN의 **Shirt**(-0.142)다. 분류기 상한을 함께 보지 않았다면 두 모델의 약점을 같은 것으로 오해했을 것이다.

## 7. 결론

**이번 설정(γ = 1, 최대 50 epoch, 시드 1개)에서는 VAE식 학습 신호를 더해도 조건부 이미지 생성이 전반적으로 좋아지지 않았다.**

| 하위 질문 | 우세 | 근거 |
| --- | --- | --- |
| Q1. 라벨을 더 잘 따르는가? | cGAN (근소) | 0.916 vs 0.902. 차이 대부분이 cVAE-GAN의 Shirt |
| Q2. 더 사실적인가? | **cGAN** | FID 10.35 vs 15.26, Precision 0.854 vs 0.826, 클래스별 FID 10개 모두 |
| Q3. 더 다양한가? | **cVAE-GAN** | Recall 0.802 vs 0.738, 다양성 비율 1.004 vs 0.962 |
| Q4. 더 안정적으로 학습되는가? | cVAE-GAN (근소) | D 출력이 0.5 근처로 균형. 단 cGAN도 불안정하지 않았음 |

- 재구성 신호는 생성자가 실제 분포를 **더 넓게 덮게** 만든다(Recall ↑). 그 대가로 개별 샘플의 사실성과 라벨 준수가 떨어진다(FID ↑, Precision ↓, Shirt 정확도 ↓).
- cVAE-GAN은 epoch당 학습 시간이 약 2배다.
- 사실적인 이미지가 중요하면 cGAN, 실제 분포를 빠짐없이 덮는 다양성이 중요하면 cVAE-GAN을 고른다.
- 결과를 해석하는 데 결정적이었던 것은 **분류기 상한과 학습 전 baseline을 같은 표에 놓은 것**이다. 상한이 없으면 Shirt 정확도가 낮은 이유가 분류기 때문인지 생성 모델 때문인지 구분할 수 없었다.

## 8. 한계와 다음 단계

- **cGAN이 아직 수렴하지 않았다.** best epoch이 마지막 epoch(50)이고 val FID가 계속 내려가고 있었다. 반면 cVAE-GAN은 epoch 25 이후 정체했다. 학습량을 늘리면 FID 차이가 더 벌어질 수 있다. → 최대 epoch을 늘려 다시 비교
- **시드가 1개다.** 조건부 정확도 차이(0.0145)나 안정성 차이는 시드에 따른 변동 범위 안일 수 있다. → 시드 3개 이상으로 반복해 평균 ± 표준편차로 비교
- **γ = 1.0 하나만 시험했다.** cVAE-GAN의 과한 질감과 Shirt 혼동은 재구성 가중치와 관련이 있을 수 있다. → γ 조정을 가장 먼저 진행
- **평가 feature 공간.** Precision/Recall, 다양성 비율, 최근접 거리는 직접 학습한 분류기 feature 기준이고, 실제 이미지도 0.88이 상한이다.
- **클래스별 FID.** 1,000장 기준이라 위로 치우친다. 모델 간 상대 비교로만 해석했다.

다음 실험은 기본 실험과 섞이지 않도록 변수를 한 번에 하나씩 바꾼다: γ 조정 → spectral normalization / hinge loss(안정성) → projection discriminator(조건 준수) → one-sided label smoothing → CAS 평가(생성 이미지로 분류기를 학습하고 실제 test로 평가) 추가.
