## 큰 그림

| 묶음 | 어디로 | 이유 |
| --- | --- | --- |
| 교회 영상 인트로들 | **Lab** 각각 1개 + **Work** 1개 "인트로 시리즈" | 인트로 하나하나는 결과물(Lab). 여러 개를 모으면 스타일 변화·제작 방식이라는 이야기가 생긴다(Work). |
| 교회 앱 | **Work** 1개 | 문제 → 과정 → 결과가 있는 대표 개발 프로젝트 |
| 코드잇 스프린트 미션 | **Log** `codeit-sprint/` 카테고리 | 미션마다 배운 것 기록. 가장 잘된 것 하나는 나중에 Work로 승격 |
